### MIDI callback rule

The native callback may validate byte length, attach the callback timestamp, copy bytes into a bounded transport event, and enqueue or signal nonblocking downstream work. It may report overflow using a preallocated/bounded mechanism. It may not call the planner, model, analysis, catalog, session journal, UI, filesystem, network, or synchronous logger, and it may not wait on a lock or promise. Semantic decode, state reconciliation, diagnostics persistence, and planning happen after the callback returns. The selected native binding does not change this rule.

### Planner process rule

Planner/model execution runs in a separate local process behind bounded asynchronous messages. Requests contain immutable capabilities, observed-state revisions, set revisions, constraints, and prepared analysis. Results are data-only proposed plans. `core/` validation and `execution/` authority/deadline checks remain mandatory before any host action. Planner delay or failure cannot block feedback, release, cancellation, takeover, or disarm.
