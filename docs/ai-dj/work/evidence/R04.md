## Resource and lifecycle bounds

The caller must split valid larger native chunks through a bounded upstream queue; it must never truncate and continue. Each partial frame retains at most 635 bytes before its final terminator. Four incomplete messages retain at most 262,144 decoded payload bytes plus fixed headers and 16-byte fragment bitmaps. A fifth message is rejected without evicting existing valid work. Identical fragment duplicates do not extend deadlines; conflicts discard the message.

A default 25 ms timer checks expiry even with no input and is unreferenced so it cannot keep Node alive by itself. Expiry runs before every push too.
