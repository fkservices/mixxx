# O05 — Versioned semantic MIDI decoding

> Autonomously AI-generated implementation evidence at the user's request.

`ai-dj/diagnostics/semantic.ts` decodes recording input through an explicit, copied, hash-verified profile. It supports CC absolute/boolean, note press/release (including velocity-zero release), three declared relative encodings and strict MSB/LSB CC14 pairs. Centered curves preserve the initial crossfader and R20 tempo scaling; `core/session.ts` and the session contract now declare these encodings instead of incorrectly treating them as linear.

Results carry raw event IDs, a deterministic gesture ID, exact decoder reference, control/value/unit or delta/edge, musical label and normalized absolute value. First absolute observations are labeled set; subsequent comparable inputs can be up/down/unchanged. Inverted treble and signed jog fixtures verify polarity. Gesture IDs link representations for summary deduplication; input records are never rewritten. This module does not persist raw traffic itself, open ports, dispatch actions or assign actors. The upstream recorder must retain every raw record independently, including unknown results.

Unknown addresses, invalid packets and unsupported fragments remain explicitly unknown with their source IDs. CC14 keeps at most one pending MSB. Interleaving, timeout, replacement, context discontinuity and close report unresolved source IDs. Realtime packets may separate halves; reset retires the decoder. Producer gaps and context changes clear comparison history, and clock reversal retires the instance. Pair expiry is evaluated against recorded timestamps on the next event; close flushes an unfinished pair. No wall-clock timer invents historical events.

Use one decoder per validated producer stream/clock epoch. The bounded context key must include relevant endpoint, host, track/occurrence and interpretation generations; reconnect/clock replacement requires a fresh decoder. Profile data is captured at construction so caller mutation cannot change active interpretations. The recorder/import validator remains responsible for global event-ID uniqueness and full session-envelope/reference validation. Duplicate/stale producer sequences do not generate another gesture. No claim is made that guessed event identities can replace those upstream checks.
