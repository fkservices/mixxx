# M14 bounded timing capture

> Autonomously AI-generated implementation evidence. No live benchmark is claimed.

The timing harness retains three independent measurement families: scheduled to
actual dispatch (signed lateness), send to loopback return (full RTT), and actual
command dispatch to independently received observation. Each endpoint explicitly
names the same local clock domain. The harness never divides RTT by two, compares
different clocks, dispatches MIDI or infers UI/audio response from feedback.

Each run sets its clock identity, per-metric sample capacity and deadline budget.
The capacity is bounded to 1–100,000 samples per metric, with one bounded ID set
per retained sample collection. Capture stores copied, frozen endpoints and
timestamps, preserves delayed arrival of earlier observations, and rejects
duplicates of retained IDs. A nonfinite, negative, throwing or regressing clock
latches a fault; a new run is required to resume capture. Invalid sample admission
does not append a record. Caller-supplied endpoint pairing remains the caller's
responsibility; conventional MIDI state matching is not a causal acknowledgement.

Summaries use nearest-rank p50/p95/p99 and maximum over the explicitly named first
retained sample window. Empty statistics are null. A sample misses its deadline
only when its interval exceeds the configured budget; equality passes. Early
dispatch remains negative rather than being hidden by clamping. Capacity drops
and externally reported unpaired/lost samples are separate counters. They mark
sample loss, and counter saturation marks overflow. These flags prevent treating
a truncated distribution as an exhaustive run. Statistics and deadline-miss
counts describe retained samples only; downstream gates must inspect loss and
clock-fault flags and require sufficient sample counts.

## Validation

Eight synthetic tests cover exact known 1–100 percentiles, metric separation,
full RTT, deadline equality, early dispatch, bounded retention, external loss,
counter saturation, cross-clock rejection, invalid timestamps, delayed arrival,
clock faults, immutable snapshots, duplicate IDs and configuration bounds.

The integrated suite passed all 122 tests with zero failures. Type checking,
the TypeScript build and whitespace validation passed. Source files are
`ai-dj/diagnostics/timing.ts` and `ai-dj/test/diagnostics/timing.test.ts`.
The graph reported no coverage for these new files; review used their direct
source and executable tests.
