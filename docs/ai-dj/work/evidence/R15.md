## Delivered

[normative rules](../contracts/modes.md) define AI Only, B2B and Playlist Only,
separate selection/gate/disarm state, mode and arming generations, expected-version
commands, bounded reconciliation, persistence and mandatory switch barriers.
They reuse F06 mode/identity/time types rather than introducing alternate names.

Already-armed AI Only/B2B switches reconcile before continuing, without another
rearm when the latch is clear. Playlist Only-to-performance selection requests
start only with a clear latch. Explicit Disarm survives mode changes and late
reconciliation. Startup restores selection alone and always starts disarmed.

B2B holds survive mode switches and require the actual later transition plus
release/quiet/freshness before reclaim. AI Only can recover ordinary adjustments
from observed state; it does not bypass operation guards. Playlist Only allows
reads/organization and explicit native playlist save, but no AI deck loading or
performance writes. Existing momentary release obligations remain scoped cleanup.
