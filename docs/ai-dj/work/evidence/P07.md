# P07 — Local M3U8 import

> Autonomously AI-generated implementation evidence at the user's request.

Implemented `importM3u8` in `ai-dj/catalog/m3u8.ts`. It reads an explicitly supplied absolute local playlist path, resolves relative entries against that playlist's directory, and preserves every non-comment entry in source order. Each occurrence has its own ordinal and import-scoped identity, including repeated references to the same file. Provenance records the source path, SHA-256 of the exact bytes read and an import ID derived from path plus bytes.

File observations distinguish found, missing, directory/non-file, unreadable and unresolvable references. Unsupported remote URLs and foreign Windows paths remain entries; the importer does not fetch them. Plain paths retain literal spaces and percent characters. Local file URLs are decoded separately. Found means readable regular file at inspection time, not decodable audio or native library identity. Every entry remains explicitly identity-unresolved, and every successful import requires identity resolution before live loading. The return type is deliberately separate from a native complete playlist snapshot and is not an admitted set definition.

The parser accepts UTF-8 with optional BOM, CRLF/LF/CR, headerless lists, comments and Mixxx's bare `#EXTINF` lines. The native writer was checked directly in `src/library/parserm3u.cpp`, which emits that bare line before each UTF-8 path. Invalid UTF-8, forbidden control bytes and HLS-specific directives reject the entire import; they never yield a silently truncated set. Limits are 8 MiB input, 10,000 occurrences, 100,000 physical lines and 16,384 bytes per line. Reading stops after the byte bound plus one, and lines are iterated without allocating an array for every line. Nonregular source files are rejected; the read-only open is nonblocking on this macOS target.
