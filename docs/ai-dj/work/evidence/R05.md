# R05 endpoint implementation and remaining native integration

> Autonomously AI-generated interim evidence. R05 is not accepted.

The endpoint factory connects the accepted host encoder and decoder. A fixed
client-opcode allowlist requires unique, explicitly supplied validator/handler
pairs; diagnostic handlers require opt-in. Configuration is copied at creation.
Decoded payloads and headers are frozen before validation. Only an exact `true`
validator result permits dispatch; missing handlers and rejected payloads do not
invoke a handler. Semantic schemas, handshake, host guards and action authority
remain the registered handlers' responsibility, not a framing-layer claim.

Native input is checked for array/typed-array shape, exact length, a 2,048-byte
cap and byte values before allocating the parser input copy. Stale-generation
callbacks are ignored. A parser failure or MIDI reset invalidates all messages
from that callback, including ones decoded before reset. Handler exceptions,
validation exceptions and reentrant receive attempts latch a fault and retire
the parser. No automatic recovery, control write or feedback echo is installed.

Output fixes the host direction and uses the documented
[Mixxx SysEx send API](https://github.com/mixxxdj/mixxx/wiki/midi-scripting).
The current clock is checked before encoding/sending. Partial send failure stops
further frames, reports an unknown outcome and never retries. Returned frame
counts are unconfirmed delivery, not host acceptance. Explicit close retires the
parser timer; cleanup errors are surfaced through the fault callback.
