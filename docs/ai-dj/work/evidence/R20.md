## Frozen profile and behavior

[Codec](../../../../ai-dj/midi/cc14.ts) implements one profile,
`ai-dj-cc14-v1`. Channel numbers below are zero-based; the UI displays 5 and 6.
Both messages use Control Change status. The MSB must precede the LSB.

| Target | Status | MSB CC | LSB CC | Value domain |
| --- | --- | --- | --- | --- |
| Deck 1 gain | B4 | 16 | 48 | Normalized parameter 0..1 |
| Deck 2 gain | B5 | 16 | 48 | Normalized parameter 0..1 |
| Deck 1 tempo | B4 | 17 | 49 | Normalized offset -1..1 |
| Deck 2 tempo | B5 | 17 | 49 | Normalized offset -1..1 |

Reconstruct `raw = MSB * 128 + LSB`, range 0..16383. Gain quantization is
`round(value * 16383)`, inverse `raw / 16383`. This is a normalized control
position, not a dB or linear-amplitude claim. Tempo uses center 8192 exactly;
negative offsets scale by 8192 and positive offsets by 8191, with nearest integer
rounding. Inverse scaling uses the corresponding side. A separately selected,
verified tempo range must translate the normalized offset to BPM/rate. The codec
never chooses that range or bypasses pitch constraints.

The synchronous writer emits the pair without yielding and rejects reentry.
Its caller must own all writes on that stream; it cannot serialize unrelated
code writing directly to the same port. Async functions are rejected before use;
an unexpected returned Promise retires the writer and has its rejection handled.
Any send failure, unexpected return or mid-pair close leaves outcome unknown and
retires the writer without retry or compensating messages. Successful return is
unconfirmed transport submission, not host acceptance.

The decoder retains one MSB for at most 20 ms. A matching adjacent LSB completes
it; reverse arrivals are orphans. A new MSB explicitly discards the pending half
and starts a new pair. Other control/channel traffic breaks the pair. Realtime
F8..FE bytes may interleave without extending its deadline; FF retires it.
Timeout is checked before consuming each current-generation input and by an
unreferenced 5 ms timer even when input stops. Event-loop stalls may delay timer
execution, but a late half still cannot complete an expired pair.

Malformed/sparse input is rejected. Increasing generation clears the half;
retired-generation callbacks cannot poison current state. Invalid/backward clock
samples retire the decoder. Pending storage is constant; discard count, latest
reason and counter saturation are explicit. There is no unbounded diagnostics
queue. Callers must record raw traffic and monitor these counters; this component
alone is not a lossless session recorder.

Bare CC pairs have no sequence or causal identity. Adjacent matching halves are
not proof they originated from the same physical gesture when transport loses or
reorders complete updates. Results explicitly say `adjacent-halves-only`. MIDI
bytes do not identify AI versus human; endpoint and event provenance remain
required. No NRPN or MIDI 2.0 behavior is implied.

## Verification and limits

[Seven focused tests](../../../../ai-dj/test/midi/cc14.test.ts) cover endpoints,
exact tempo center, pair bytes, quantization, reentry, transport failure, invalid
async transport, reverse/interleaved halves, realtime insertion, timeout/idle
expiry, malformed/sparse bytes, generation changes, clock fault and MIDI reset.

Across 10,001 synthetic values per control, accumulated absolute reconstruction
error was less than one hundredth of the corresponding 7-bit mapping. Maximum
error stayed within half a 14-bit step. This measures mathematical reconstruction,
not native widgets, hardware resolution, latency or audible quality.

Integrated checks passed: 161 tests, no failures/skips/cancellations, TypeScript
typecheck and build. No old test was removed or weakened.

This profile is deliberately unbound. The inspected native mapper in
[midicontroller.cpp](../../../../src/controllers/midi/midicontroller.cpp) uses its
own queue and scaling behavior; these tests do not certify that mapper as this
codec. Native integration must establish matching scaling, timeout and source
semantics before advertising the feature. Existing 7-bit registration remains
unchanged. Feature inventory, host admission and final coverage gates still
require that integration evidence.
